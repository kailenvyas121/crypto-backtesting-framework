# Data map

Provenance for every dataset. A file in `data/processed/` with no builder script and no
entry here is orphaned: it cannot be regenerated and should not be trusted.

## Source notes

**Coinbase BTC-USD vs BTC-USDC.** On the Coinbase Advanced Trade API the two return
identical candles, byte for byte, back to 2016 -- two years before USDC existed. Coinbase
serves the unified USD book under both names. BTC-USD is therefore the canonical series
and the longest one (from 2015-07-20). Checked 2026-09-29 on three 300-bar windows
(2016-06, 2021-06, 2025-06). The legacy Coinbase Exchange API lists BTC-USDC as inactive.

**Daily close convention.** Crypto: Coinbase daily candles, 00:00-24:00 UTC, stamped with
the open time. Institutional alternatives exist -- the CME CF Bitcoin Reference Rate
(4pm London) and its New York variant BRRNY (4pm ET, used for spot BTC ETF NAVs) -- and
matter when crypto is aligned against equity closes; they are not used here.
Equities: the official NYSE closing auction (16:00 ET, 13:00 on early-close days), with
sessions from the `XNYS` calendar in `exchange_calendars`.

### btc_buy_hold_2022_2026-08.csv

- Builder: `scripts/build_btc_buy_hold.py`
- Input: `data/raw/market/crypto/coinbase/BTC_USD_1d.parquet` (BTC/USD, Coinbase)
- Range: 2021-12-31 (entry close) to 2026-08-31 (final mark), 1,705 rows = entry + 1,704 daily returns
- Columns: close, signal, position (held, lag 1), asset_ret, strategy_ret (simple), equity, drawdown
- Caveats: gross of fees and slippage. Row 1 is the entry mark; its returns are NaN by design.
